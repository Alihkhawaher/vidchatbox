How to Get API Keys

OpenRouter — One key for all cloud AI features (transcription, chat, translation)

  1. Visit openrouter.ai/keys
  2. Sign up or log in (Google/GitHub login supported)
  3. Click "Create Key"
  4. Copy the key (starts with sk-or-)
  5. In YouTube Lang Tools → Settings → paste in "OpenRouter API Key"
💡 Cost: Transcription ~$0.024/video. Chat ~$0.01/message. Translation ~$0.001/video. Most features cost less than $0.05 per video.
Google API Key Optional
  1. Go to Google Cloud Console
  2. Create a project → Enable Gemini API
  3. Go to APIs & Services → Credentials
  4. Click "Create Credentials" → "API Key"
  5. Paste in YouTube Lang Tools → Settings → "Google API Key"
Claude API Key Optional
  1. Visit console.anthropic.com
  2. Sign up or log in
  3. Navigate to API Keys → "Create Key"
  4. Paste in YouTube Lang Tools → Settings → "Claude API Key"
🔒 Privacy: All API keys are stored locally in your browser (localStorage). They are sent only to the respective API providers via our server proxy — we never store or log them.
